# Ключ к процветанию — руководство

Версия 6: настоящие карточки (25 колод, 618 карт), реальные вопросы для
рефлексии, проверка ответа на осмысленность. Игровое поле — теперь просто
красивый фон, попадание на колоду полностью случайное.

## Игровой цикл (5 ходов)

1. Игрок вводит желание.
2. Бросает кубик (чисто ритуальный жест — на результат не влияет).
3. Игра случайно выбирает одну из 25 колод (за партию — 5 разных колод,
   без повторов) и показывает её ОБЛОЖКУ (настоящую картинку из папки
   колоды).
4. Игрок открывает колоду — видит РОВНО столько карт рубашкой вверх,
   сколько их реально в этой колоде (от 17 до 35), и выбирает одну вслепую.
5. Карта переворачивается — показывается расшифрованный текст (саму
   фотографию карты не показываем, качество плохое).
6. Игра задаёт вопросы:
   - для 7 "негативных" колод — у каждой СВОИ вопросы;
   - для 17 "позитивных" колод — один универсальный набор из 3 вопросов;
   - для колоды "Награда" — вопросов нет, только поздравительное сообщение.
7. Перед тем как продолжить, игра проверяет, что ответ содержательный (не
   случайные буквы/цифры, не пустая отписка) — иначе просит дописать.
8. Игра даёт напутствие и переходит к следующему ходу.
9. После 5 хода — финальный экран.

Счётчик хода на экране не показывается (так решил Рамиль) — но их ровно 5.

## Про колоды и вопросы (`src/data/cards.js`)

- `DECKS` — объект из 25 колод. У каждой: `mode` (`negative` / `positive` /
  `reward`), `cover` (путь к обложке в `public/covers`), `symbol`, `color`
  и полный список `titles` — все настоящие карточки этой колоды.
- `NEGATIVE_QUESTIONS` — вопросы для 7 негативных колод (свои для каждой).
- `UNIVERSAL_QUESTIONS` — 3 вопроса, общие для 17 позитивных колод.
- `REWARD_MESSAGE` — фиксированное сообщение для колоды "Награда".
- `pickGameDecks(5)` — выбирает 5 случайных РАЗНЫХ колод на партию.
- `drawFullDeck(deckName)` — перемешивает и возвращает ВСЕ карты колоды —
  именно столько карт показывается рубашкой вверх.
- `isAnswerSubstantive(text)` — эвристика проверки, что ответ осмысленный:
  минимальная длина, минимум 2 разных слова, минимум 5 разных символов,
  достаточно букв. Не идеальная (это не ИИ-проверка, а простая эвристика),
  но отсекает совсем пустые/случайные ответы.

Если захочешь поправить конкретную карточку или вопрос — просто отредактируй
текст в массиве `titles` или в `NEGATIVE_QUESTIONS` / `UNIVERSAL_QUESTIONS`.

## Про напутствие после вопросов

Настоящих индивидуальных напутствий на каждую из 618 карточек нет, поэтому
после ответа на вопросы игра показывает одно из двух тёплых обобщённых
напутствий — для негативных колод и для позитивных (см. `GUIDANCE` в
`CardScreen.jsx`). Если захочешь — можно заменить на что-то более
персональное под каждую колоду.

## Как запустить локально

1. Установи Node.js (nodejs.org) — проверить: `node -v`.
2. `cd путь/до/klyuch-k-procvetaniyu`
3. `npm install`
4. `npm run dev`
5. Открой адрес из терминала (обычно `http://localhost:5173`).

## Деплой на Vercel и подключение к боту

1. Загрузи папку проекта в репозиторий на GitHub.
2. На [vercel.com](https://vercel.com) → Add New → Project → выбери репозиторий → Deploy.
3. Получишь ссылку вида `https://....vercel.app`.
4. В Telegram у **@BotFather**: `/mybots` → бот → Bot Settings → Menu Button → Configure Menu Button → вставь ссылку с Vercel.
5. Открой бота и нажми кнопку меню — проверь игру.

## Если что-то не работает

- Белый экран локально — открой консоль браузера (F12 → Console).
- Не видно обложек колод — проверь, что папка `public/covers` (25 файлов
  `.jpg`) скопировалась вместе с проектом.
- Белый экран только в Telegram — ссылка должна быть `https://`, и деплой на Vercel должен быть завершён.
